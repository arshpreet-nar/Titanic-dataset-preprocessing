# Titanic Data Cleaning and Preprocessing

This repository contains the deliverables for Edutech Solution Data Analytics Internship Task 2.

## Task

Clean and preprocess the Titanic dataset using Python, Pandas, and NumPy.

## Files

- `data/raw/Titanic-Dataset.csv` - original dataset used for the task.
- `preprocess_titanic.py` - complete preprocessing code.
- `Titanic_Preprocessing.ipynb` - notebook version of the preprocessing workflow.
- `data/processed/titanic_cleaned.csv` - cleaned dataset generated by the script.
- `data/processed/cleaning_summary.txt` - short summary of cleaning actions.
- `reports/Titanic_Data_Preprocessing_Report.docx` - professional report for the task.
- `interview_questions.md` - answers to the interview questions from the task PDF.
- `requirements.txt` - Python packages used.

## Cleaning Steps

1. Loaded the raw Titanic dataset.
2. Removed duplicate rows.
3. Handled missing values:
   - `Age`: filled with median age.
   - `Embarked`: filled with mode.
   - `Cabin`: converted into `Cabin_Known` and `Cabin_Deck`.
4. Created `FamilySize` and `IsAlone` features.
5. Capped numeric outliers using the IQR method.
6. Normalized numeric features using min-max scaling.
7. Encoded categorical columns such as `Sex`, `Embarked`, and cabin deck.
8. Dropped raw text columns that are not directly useful for basic modeling.

## How to Run

```bash
python preprocess_titanic.py
```

After running the script, the cleaned file will be saved at:

```text
data/processed/titanic_cleaned.csv
```

## Output

The final cleaned dataset has no missing values and includes normalized numeric features plus encoded categorical features.
